# AOTC v0.2: Arrays, Calls, FFI, Parallel

AOTC v0.2 extends the compiler from scalar loops to a memory-aware subset.

## Highlights
1. Static arrays lowered to LLVM memory operations (`alloca`, `gep`, `load`, `store`)
2. Strict native-to-native call lowering with module-level signatures
3. Extern C interop using `@extern("m")` and linked `sin/cos`
4. Parallel runtime APIs: `@native(parallel=True)`, `@parallel`, `parallel_for`
5. Build/runtime support improved for Linux/macOS/Windows

## Commands
```bash
aotc build examples/array_sum.py --emit so --opt O3 --passes cf,dce,inline
aotc bench --loop-count 10000000 --repeats 3 --threads 8 --opt O3
```
